# OverTheWire : Natas 0 
### Goal
Find the password for Natas1.

### What I Observed 
The webpage itself did not reveal any useful information.

### What I Did 
Since web applications often contain hidden information in the client-side source code, I inspected the page source using the browser's "View Page Source" feature.

### What I Found 
The password for the next level was exposed within the HTML source code.

### What I Learned
- Always inspect the page source during web enumeration.
- Information hidden from the visual interface may still be accessible to users.
- Client-side data should not be considered secret.
